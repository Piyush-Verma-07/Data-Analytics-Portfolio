# 🛒 E-commerce Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive E-commerce Sales Dashboard built using Microsoft Power BI. It analyzes sales performance, profitability, product categories, payment methods, customer contributions, and regional performance.

The dashboard helps explore business performance through key performance indicators (KPIs) and visualizations.

## 📊 Dashboard Preview

![E-commerce Sales Dashboard](dashboard.png)

## 🎯 Project Objectives

- Analyze overall sales and profitability.
- Understand product category performance.
- Examine monthly profit trends.
- Explore customer-level sales contributions.
- Analyze payment method preferences.
- Compare profitability across product sub-categories and states.

## 📈 Key Performance Indicators

The dashboard displays the following metrics:

- **Average Order Value:** Average value per order.
- **Total Profit:** Overall profit generated.
- **Total Quantity:** Total quantity of products sold.
- **Total Amount:** Overall sales amount.

## 📉 Dashboard Features

### 1. Monthly Profit Analysis
Visualizes monthly profit trends to identify profitable and loss-making periods.

### 2. Payment Method Analysis
Examines product quantities across different payment methods, including UPI, credit cards, debit cards, and cash.

### 3. Product Category Analysis
Compares quantities sold across categories such as Clothing, Electronics, and Furniture.

### 4. Customer Sales Analysis
Displays sales amounts associated with individual customers.

### 5. Product Sub-Category Profitability
Compares profit across product sub-categories, such as Printers, Bookcases, Sarees, Accessories, and Tables.

### 6. State-Level Profit Analysis
Explores profit distribution across states, including Maharashtra, Madhya Pradesh, Uttar Pradesh, and Delhi.
